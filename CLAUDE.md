## Claude Code

- Відповідати й писати коментарі українською.
- Dev-сервер для перевірки в браузері — конфігурація `dev` у `.claude/launch.json`
  (`npm run dev`, порт 5173); прод-збірка — `preview` (порт 4173, після `npm run build`).
- Перевіряти вигляд на 375 px і на десктопі; консоль браузера — без помилок і попереджень React.
- Перед звітом «готово» — `npm run lint` і `npm run build`; якщо щось не пройшло, сказати прямо
  з виводом команди.
- Пропозиції, які змінюють стек чи структуру, — не впроваджувати самостійно: описати з
  обґрунтуванням і дочекатися рішення.
